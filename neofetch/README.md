# neofetch

Install neofetch by following https://github.com/dylanaraps/neofetch/wiki/Installation

## Setup

Symlink the config file:

```sh
ln -s ~/dotfiles/neofetch/config.conf ~/.config/neofetch/config.conf
```

Symlink the ASCII art directory:

```sh
ln -s ~/dotfiles/neofetch/ascii ~/.config/neofetch/ascii
```
